# 📝 Habit Tracker

A modern Habit Tracker web application built with **React** and **Tailwind CSS** to help users build consistent habits, track progress, and stay motivated.

## ✨ Features

- ✅ Add new habits
- ✏️ Edit existing habits
- 🗑️ Delete habits
- ✔️ Mark habits as completed
- 🔥 Daily streak tracking
- 📊 Progress statistics
- 📅 Calendar view
- 🌙 Dark & Light mode
- 💾 Local Storage support
- 📱 Responsive design

---

## 🛠️ Tech Stack

- React
- Tailwind CSS
- JavaScript (ES6+)
- Vite

---

---

## 🚀 Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd habit-tracker
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
